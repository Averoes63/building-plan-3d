Assistance

Une question, un problème, une suggestion ? Nous répondons à chaque demande.

Nous contacter

Ouvrir une demande d'assistance (compte GitHub gratuit requis). Indiquez le modèle de votre appareil, la version d'iOS et la version de l'app (Réglages de l'app → À propos).

Ne publiez pas d'informations personnelles dans une demande : elles sont visibles publiquement.

Questions fréquentes

Quels appareils peuvent scanner ?

Le scan 3D utilise RoomPlan d'Apple et nécessite un iPhone ou un iPad équipé du capteur LiDAR (modèles « Pro »). Sur les autres appareils, vous pouvez dessiner le plan au doigt et saisir les cotes au télémètre.

Faut-il un compte ?

Non. Toutes les fonctions marchent sans compte, et vos projets restent sur votre appareil. Un compte gratuit n'est nécessaire que pour partager un chantier par lien web avec un client.

Comment scanner plusieurs étages ?

Avant de lancer le scan, indiquez l'étage où vous vous trouvez. Quand vous changez de niveau, touchez le bouton ↕ (Monter / Descendre) : le relevé de l'étage quitté est enregistré, puis le scan reprend sur le nouveau. Le plan 2D propose une vue « Tous les étages ».

Comment gérer ou résilier mon abonnement ?

Sur votre appareil : Réglages → [votre nom] → Abonnements → Building Plan 3D. La résiliation prend effet à la fin de la période en cours. Pour récupérer un abonnement sur un nouvel appareil, utilisez « Restaurer mes achats » dans l'app.

Comment supprimer mon compte ?

Dans l'app : Réglages → Compte → Supprimer mon compte. La suppression est immédiate et définitive, et révoque vos liens de partage.
